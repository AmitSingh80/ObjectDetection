Basic workflow
Webcam
   ↓
Capture Video Frame
   ↓
YOLOv8 Object Detection
   ↓
Identify Objects
   ↓
Generate Bounding Boxes
   ↓
Count Detected Objects
   ↓
Display Annotated Frame
   ↓
Repeat Until 'q' is Pressed

# Key Features
Real-Time Detection

The system detects objects continuously from the webcam feed.

Bounding Boxes

Detected objects are highlighted using bounding boxes.

Object Counting

The application counts the number of detected bounding boxes in each frame.

Live Visualization

Detection results are displayed immediately on the video feed.

Lightweight Model

YOLOv8 Nano is used because it is relatively lightweight and suitable for faster inference on systems with limited computational resources.

Easy to Use

The application requires only a webcam and can be controlled using the keyboard.
